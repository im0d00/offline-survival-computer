Offline Tile Setup

By default this map uses OpenStreetMap tiles (requires internet). For fully offline use, download tiles using SAS Planet, MOBAC, or wget and place them at data/maps/tiles/{z}/{x}/{y}.png. Then update MAPS_TILE_URL in your .env file.

Alternatively, serve MBTiles with a local tile server like TileServer GL and point MAPS_TILE_URL to it.
