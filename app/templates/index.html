Getting Started
  1. Add content to Kiwix – download .zim files (Wikipedia, Khan Academy, First Aid, etc.) and place them in the data/zim/ folder. Kiwix will serve them automatically.
  2. Pull an AI model – run docker compose exec ollama ollama pull llama3 to download a language model.
  3. Download offline maps – use the Maps page to cache map tiles for your region so they work without internet.
  4. Start taking notes – use the Notes module to record procedures, contacts, or any survival-critical information.
